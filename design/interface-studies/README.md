# 怪兽猎人 · 三种界面方向

**选型结果：2026-10-18 用户采纳 C「猎场战图」。** 后续全游戏的公共设计约定与场景盘点见 `../atlas-system/README.md`、`../atlas-system/scene-coverage.md`；此目录保留三稿供参考，不代表正式游戏已完成改版。

总览：<http://127.0.0.1:8890/design/interface-studies/overview.html>。点击卡片进入方案，也可在方案顶部切换三稿。

| 方向 | 构图和视觉 | 最适合的体验 |
| --- | --- | --- |
| A 烛火手记 | 深苔色书脊、暖色纤维纸、左右书页、墨迹图鉴、实体骰子 | 沉静阅读、连续填格、保留原版纸笔气质 |
| B 荒境远征 | 全屏险境、完整巨兽、克制的黄铜色文字、下方决策台 | 最强的场景代入与巨兽压迫感 |
| C 猎场战图 | 手绘地形、三个可点选猎场、追踪路线、朱红行动按钮、右侧记录纸 | 同时理解猎场、村庄防御与探索进度 |

三稿使用同一局面：第六天、生命 7/10、怀疑 6/18、决心 2；雪峰追踪 2/3，海岸 1/3，裂痕 0/3；南方塔竣工，小屋 9/9。第六天是巨兽袭击日，风险提示与原规则一致。

## 可体验的内容

- 切换三种界面；三处区域的名称、场景、怪兽、材料与追踪状态对应变化。
- 掷两枚骰子，选择一枚填入空格，三轮填写六个数字；实际计算三位数差值，按仓库 `GAME_DATA.searchResults` 显示结果，记入当前样稿。
- 行囊、图鉴、防御、手记、休息代价、规则弹窗。防御塔直接读取原游戏塔形。
- 手机、平板、桌面布局；移动端在上方保留生命、怀疑和决心；键盘焦点、Esc 关闭弹窗、减少动态效果设置。

这是供选择视觉方向的独立交互样稿，不是正式游戏的新发行版。状态只存在内存，不读写原游戏存档。正式游戏的 `index.html`、`css/`、`js/` 均未修改。确认方向后可接入现有完整搜索、战斗、建造、锻造和事件逻辑；当前未尝试另写一套完整规则引擎。

## 文件与素材

- `index.html`、`studies.css`、`studies.js`：三稿及交互。
- 原版区域水彩和怪兽素描复用仓库 `assets/`。
- B 的环境及完整怪兽来自本项目既有宣传片概念美术，复制为 `assets/*-scene.webp`、`*-figure.webp`，不依赖被忽略的 promo 目录。
- C 的地图由**内置 image_gen** 根据原游戏封面作风格与世界参考生成。最终原图是 `assets/hunting-map.png`，网页使用 `assets/hunting-map.webp`。完整提示词及来源见 `assets/art-direction.json`。
- 标识与图标是代码原生 SVG；字体使用本机宋体、系统中文与 Georgia，无外部字体或服务请求。没有再加入程序火焰、粒子爆团等装饰特效。

## 预览与检查

从仓库根目录运行 `python3 -m http.server 8890 --bind 127.0.0.1`。

`review/check.cjs` 用本机浏览器检查三个桌面方案、320/390px 手机和 768px 平板；同时验证区域切换、掷骰三次、六格放置、差值结算、记录更新、行囊、防御与 Esc 关闭。报告 `review/checks.json`，成图 `review/*-interface.png`。无需 npm 安装；检查脚本使用当前 Codex 随附的 Playwright。
