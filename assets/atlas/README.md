# C · 猎场战图素材

- `hunting-map.webp`：采用已选 C 稿的同一张地图，原图由内置 `image_gen.imagegen` 生成，以本项目既有封面作风格与世界参考；1536 × 1024，WebP。提示词及生成记录见 [art-direction.json](../../design/interface-studies/assets/art-direction.json)。这是一张用于氛围的地理插画，不替代游戏地区与袭击规则。
- `paper-grain.svg`：随 C 稿编写的轻微 SVG 纸张纹理；不承载文字、格子或操作。
- `village-base.webp`：村庄近景地面与固定建筑，1536×1024；议事厅、工坊、营地融入底图，住宅和防御塔由独立图层承载真实状态。
- `village-huts.webp`：两格透明住宅图集，完好／废墟；`village-towers.webp`：三格透明塔图集，未完工／完工／废墟。三张村庄素材均由内置 `image_gen.imagegen` 生成，再转换为WebP；原图来源、完整提示词和实际锚点见 [village-art.json](village-art.json)。
- 巨兽素描及地区水彩：继续使用既有 `assets/monsters/`、`assets/regions/` 中的原素材，由游戏数据引用；未替换为另一套角色画风。

正式游戏仅依赖本目录文件，样稿可以独立保留或归档。中文字体使用系统宋体和系统无衬线字体，数字使用 Georgia，无需外部字体服务。
